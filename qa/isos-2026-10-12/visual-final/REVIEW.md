# 국문 PC 독립 시각 검수

검수일: 2026-10-12. 대상은 로컬 최신 빌드 `http://127.0.0.1:4173/`의 한국어 화면이다. Chromium 1440×1000을 기본으로 ABOUT, PROCESS, TEAM, WORKS, 홈, CONTACT, PRIVACY를 직접 렌더링했다. PROCESS는 1440×700/600에서도 추가 확인했다. 영어·모바일·사이트 소스는 수정하지 않았다. 브라우저의 변경 요청은 차단했고 실제 시도된 변경 요청은 0건이다.

## 판단

이전의 같은 모양 서브페이지보다 페이지별 리듬이 분명해졌다. ABOUT의 밝은 2열, TEAM의 큰 중앙 타이포그래피와 민트 배경, PROCESS의 outline 제목과 한 장면, CONTACT의 밝은 진입이 각각 다른 역할을 한다. 새로운 효과의 수보다 읽기 순서와 선택 이후 정보의 연결이 개선된 점이 크다.

검수한 최종 정지 상태에서 글자 잘림, 가로 넘침, 본문과 제어의 겹침, 캡처 비율 손상은 발견하지 못했다. 최초 지적한 TEAM 전환 대비, WORKS 탭 줄바꿈, CONTACT 파일 선택 표시는 수정 후 표적 재검수에서 모두 해결됐다. 이번 기록은 시각 검수이며 다른 담당자의 3개 브라우저 기능 시험을 대신하지 않는다.

### 낮은 화면 높이의 PROCESS

- 1000px: 네 단계의 텍스트·산출물과 왼쪽 단계 제어가 함께 보인다.
- 700px: 고정 무대는 y=130~591, 네 링크는 y=520~591이다.
- 600px: 고정 무대는 y=130~557, 네 링크는 y=486~557이다.
- 700/600px의 모든 링크 중앙은 `elementFromPoint`로 해당 링크에 닿았다. 본문은 자연스럽게 스크롤되며 고정 장면에 가려지지 않았다.
- 600px 미만 높이는 이번 검수에 포함하지 않았다.

## 최초 지적과 수정 후 재검수

**TEAM 클릭 직후 새 본문의 낮은 대비.** `team-switch-220ms.png`에서는 인플루언서 탭은 이미 선택됐지만 제목·설명·산출물·CTA가 거의 읽히지 않는다. 정적 코드의 `opacity: .06`에서 시작하는 텍스트 전환이 0.26초 뒤 시작되는 조건과 일치한다. 1.4초 뒤에는 정상적으로 읽힌다. 사용자가 필요한 역할을 빨리 비교할 때 본문이 잠시 사라지는 인상을 주므로 제목·CTA를 즉시 유지하거나 텍스트 시작 시간을 앞당기고 초기 대비를 높이는 편이 낫다. 조형의 선 그리기와 회전은 현재처럼 별도로 유지할 수 있다. 기능 차단 결함은 아니지만 완성도에 직접 영향을 주는 항목이다.

그 외 최초 마감 지적은 WORKS 서비스 탭의 두 줄 균형, 문의 첨부 선택의 한글 표현이었다. 세 항목 수정 후에 이 세 화면만 같은 1440×1000 환경에서 다시 확인했다.

1. **TEAM: 해결.** 탭 클릭 220ms 후 조형은 아직 전개 중이지만 제목·설명·산출물·CTA는 모두 `opacity: 1`, `transform: none`, `visibility: visible`이다. 실제 캡처에서도 선택한 역할과 본문이 즉시 함께 읽힌다.
2. **WORKS: 해결.** 10개 탭이 너비 222px로 동일하고 첫 5개는 y=174.59, 다음 5개는 y=231.59에 정렬된다. 마지막 항목이 홀로 내려가는 모습이 사라졌다.
3. **CONTACT: 해결.** `파일 선택`, `선택한 파일이 없습니다`와 파일 규격 안내가 국문으로 표시된다. 버튼·안내·동의·전송 사이의 간격도 안정적이다. 이 시각 재검수에서는 파일을 선택하거나 전송하지 않았다.

재검수 JavaScript 오류와 변경 요청은 모두 0건이다. 이번에 제시한 구체적인 시각 수정 사항 중 미해결 항목은 없다. 모든 영역에 더 많은 모션을 추가할 필요는 없다.

## 현재 내부 평가

아래 평가는 이 한국어 PC 구현의 내부 검토다. 수상 가능성이나 Awwwards 등 외부 평가의 인증이 아니며 기능 시험의 통과 개수를 미적 점수로 환산하지 않았다.

| 기준 | 점수 | 근거 |
|---|---:|---|
| 정체성 | 23/25 | 제공된 실제 로고에서 확장한 입체 심볼과 민트·잉크·타이포그래피가 일관된다. 일부 서비스의 아이콘 표현은 여전히 범용적이다. |
| 구성 | 18/20 | 페이지별 첫 장면과 PROCESS의 읽기 구조가 개선됐다. 큰 상징 영역과 반복되는 넓은 패널은 실제 산출물과 결합해 더 정교해질 수 있다. |
| 모션 | 18/20 | 단어 마스크·문장 강조·SVG 선·선택 전환·포트폴리오 창이 서로 다른 역할을 가진다. 더 높은 수준에서는 공통 등장 문법보다 개별 콘텐츠의 관계를 설명하는 장면을 늘릴 여지가 있다. |
| 마케팅 내용 | 17/20 | 제작자 프로젝트와 콘셉트를 정확히 구분하면서 실제 제작 화면을 보여주어 역량의 폭이 보인다. 역할별 산출물도 구체적이다. 종합 광고·PR의 판단 과정과 확인 가능한 실행 결과는 아직 상대적으로 부족하다. |
| 사용성 | 14/15 | 이번 시각 범위에서 제어의 접근·본문 읽기·짧은 높이의 고정 장면·이미지 비율이 안정적이다. 일부 안내·메타데이터는 작은 보조 글씨에 의존한다. |
| 합계 | **90/100** | 1차 완성도 목표에 해당하는 내부 평가다. 국제 수상 수준을 충족했다고 단정하지 않는다. |

기존 내부 평가 89점에서의 주된 증가는 제작 사례의 확충과 역할별 구체 산출물이다. 페이지별 레이아웃과 모션의 차이는 이전 감점을 줄였지만, 큰 상징 영역·반복되는 패널·광고와 PR의 실행 근거라는 한계가 있어 구성·모션 점수를 일괄 상향하지 않았다.

## 증거

- `capture.cjs`: 읽기 전용 캡처 절차. 실제 문의 제출 없음.
- `observations.json`: 28개 관찰 지점, 화면 크기·활성 단계·가시 이미지·제어 위치·오류·변경 요청 기록. JavaScript 오류 0건, 관찰 지점의 문서 너비 모두 1440px.
- `*-top.png`: 7개 페이지의 첫 화면.
- `about-reading.png`, `about-principles.png`: 문장과 원칙의 읽기 상태.
- `process-step-1.png`~`process-step-4.png`, `process-nav-click.png`, `process-short-700.png`, `process-short-600.png`: 단계별 상태와 짧은 높이.
- `team-role-1.png`, `team-role-7.png`, `team-role-9.png`, `team-switch-220ms.png`: 선택 후·전환 중 상태.
- `home-project-*.png`, `works-project-*.png`: 실제 작업 캡처와 제목.
- `contact-form.png`, `privacy-reading.png`: 입력·본문 가독성.
- `team-recheck.cjs`, `team-recheck.json`: 3개 지적의 표적 재검수와 수치.
- `team-switch-220ms-fixed.png`, `works-service-tabs-fixed.png`, `contact-attachment-fixed.png`: 최종 수정 상태. 해당 항목의 이전 캡처보다 이 세 장이 최신 판정이다.

이 문서 작성 시점에 사이트 소스의 추가 수정은 하지 않았다. 후속 수정이 생기면 해당 항목만 표적으로 재확인해야 한다.
