## 확인한 동작

- 기본 7경로: 홈, ABOUT, PROCESS, TEAM, WORKS, CONTACT, 소적두 상세. 각 경로를 PC 1440×1000에서 3브라우저로 검사했다.
- 소적두 관련 문구·이미지·링크는 WORKS를 끝까지 펼쳤을 때의 단일 포트폴리오 카드와 소적두 상세에서만 발견된다. 홈 대표 사례에서는 빠져 있다.
- 홈에는 서로 다른 대표 사례가 3개 표시된다. 히어로 3탭의 선택·Home/End/방향키, 탭당 한 패널 표시, 실제 이미지 로드와 캡션 경계를 확인했다.
- 홈 서비스 8개, WORKS 서비스 10개, TEAM 역할 9개를 전부 선택해 본문·산출물·CTA 표시, 선택 상태와 키보드를 확인했다. TEAM 디자인은 `design` 자료로 콘텐츠와 분리되어 있다.
- 홈과 PROCESS의 4단계 출력, 스크롤 단계 활성화, 실행 중 감소 모션 전환 시 원래 4개 출력 복원, 모션 재활성화 시 중복 없는 복원을 확인했다.
- 선택 패널과 각 페이지의 표시 이미지 로드·대체텍스트, 문서 가로 넘침, CONTACT 미전송 상태를 확인했다.
- 마지막 CSS는 리테일 상품을 `cover`, 문자가 포함된 문화·의료 표지를 `contain`으로 표시한다. 3브라우저의 계산 스타일과 캡처로 확인했다.
- 신규 `ezylens-studio`, `city-culture`, `jonghae-community`, `patient-guide` 상세의 9개 본문 필드가 공개 API 값과 일치한다. 실제 사례의 제목·정규 URL·작업 성격, 대표 이미지 로드·확대·Escape 후 초점 복귀를 확인했다. 각 ‘비슷한 프로젝트 상담’ 링크를 따라가 프로젝트 slug가 문의 내용의 참고값에 전달되는 것까지 확인했다. 제출은 하지 않았다.

## 업종·산출물 구분

새 소스는 리테일 선택 경험, 여행 서비스, 공익·교육 기관 콘텐츠, 의료 방문 안내, 제조 제품 PR, 여행·공간 영상 콘티, 문화 옥외 포스터, 뷰티 협업 브리프, 콘텐츠 편집·운영 소프트웨어로 구분한다. 화면의 실제 제작·시제품·자체 콘셉트 표기를 검수했다. 히어로와 ABOUT 최종 캡처를 직접 열어 제품·기관 웹·포스터·의료 안내의 주제가 구별되는 것도 확인했다. 고객 납품이나 광고 성과를 입증하는 검사는 아니다.

## 실행 환경 오류와 원본 보존

1. 첫 실행은 Chromium 7경로를 완료한 뒤 Firefox `browserContext.newPage`의 sandbox `_page` 오류로 중단됐다. 사이트 페이지가 생성되기 전의 오류다. `initial-chromium-sandbox.json`에 보존했다.
2. 승인된 읽기 전용 실행에서 Firefox 7경로가 완료됐다. WebKit의 `/about/` 요청은 root의 마지막 CSS 빌드와 겹쳐 일시 HTTP404를 받고 `main` 대기 시간이 초과됐다. `firefox-webkit-build-overlap.json`에 원본을 남겼다.
3. root가 빌드·소스를 동결한 뒤 WebKit 미완료 6경로만 다시 실행해 122/122를 확인했다. `webkit-completed.json`에 보존했다.
4. `merge-results.cjs`는 같은 이름의 최신 검사만 반영한다. 환경·빌드 중단 이벤트는 삭제하지 않고 최종 JSON의 `executionEvents`와 원본에 남겼다. 전체 회귀를 반복 실행해 숫자를 누적하지 않았다.

## 재현 스크립트

- `capture-baseline.cjs`: 변경 전 HTTP 기록. 이미 보존된 `before/`를 덮어쓰므로 최종 재현 시 실행하지 않는다.
- `http-check.cjs`: 공개 HTML·API·이미지 GET 검사.
- `check.cjs`: 새 국문 빌드의 3브라우저 회귀. `TEST_BROWSERS`, `TEST_ROUTES`로 표적 범위를 지정할 수 있다.
- `fit-check.cjs`: 마지막 이미지 표시 CSS의 3브라우저 표적 검사.
- `new-cases.cjs`: 신규 4사례의 Chromium 표적 검사.
- `merge-results.cjs`: 이번 실행에서 보존한 원본들의 중복 없는 최종 집계.
