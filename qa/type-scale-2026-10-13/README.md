## 증빙과 재실행

- `baseline/snapshots.json`: 변경 전 24개 화면의 원본 측정값. 덮어쓰기를 막아 보존한다.
- `final/snapshots.json`: 최종 빌드 24개 화면의 측정값. 같은 폴더에 개별 JSON과 뷰포트 스크린샷이 있다.
- `comparison.json`: 최종 1,280개 검사, 변경·유지 요소 목록, 정확한 글자 크기·행간 비교.
- `final/artwork-preservation.json`: 최종 스냅샷의 작품 요소 240개 보존 확인. 위 비교 검사에 이미 포함된 항목의 정리이며 추가 검사 수로 합산하지 않는다.
- `first-pass/current/`, `first-pass/comparison.json`: 최종 보완 전 원본 결과.
- `first-pass/artwork-and-clipping.json`: 작품 보존과 1차 잘림 진단 기록.
- `first-pass/project-image-source-comparison.json`: 공개 프로젝트 14건의 이미지 출처 필드 보존 기록.

`snapshot.cjs`는 선택자, 직접 텍스트, 입력 안내문, 글자 크기, 행간, 서체, 두께, 영역 좌표, 노출 상태, 숨은 패널 및 컨트롤 치수를 기록한다. 최종 측정은 `TYPE_PHASE=final`로 수집했고 `TYPE_COMPARE_PHASE=final`로 `compare.cjs`를 실행했다. 검사 과정의 앱 소스 수정이나 빌드는 없다.
