# TEAM · CONTACT 통합 및 확대 UI 검수

2026-10-13, 실제 로컬 빌드 `http://127.0.0.1:4173/`. Chromium·WebKit 독립 컨텍스트, 1440×900 및 390×900. 기존 IAB 탭에 접근하지 않았으며 소스 수정·빌드·문의 전송 없이 검수했다.

최종 결과: **199개 고유 검사 중 199개 통과**. JavaScript 오류 0, 콘솔 오류 0, 쓰기 요청 0. 이전 독립 모듈 fixture의 42개나 앞선 빌드의 검사를 이 수치에 더하지 않았다.

## 실제 통합 화면

- TEAM: 기존 역할 9개와 선택 동작, 새 책 내지·Kings 메뉴 화면 2개 및 협업 설명이 함께 존재한다. 역할 탭의 터치 영역은 48px 이상이다.
- CONTACT: 기존 문의 폼 하나를 유지하고 새 사례·준비자료·FAQ를 뒤에 배치했다. 추가 폼은 없으며 FAQ 4개 모두 열린다. 전송 버튼은 누르지 않았다.
- 데스크톱 콘텐츠 폭은 1280px, 390px 화면의 콘텐츠 폭은 358px다. 새 섹션 간격은 PC 96px·모바일 64px다.
- 보이는 기본 버튼은 높이 48px·모서리 8px, 일반 입력 필드는 높이 48px·모서리 8px다. 본문 행간 비율은 1.4–1.7 범위에 들어온다.
- 실제 자산 4개는 로드 후 원비율을 유지하며 PC·모바일 가로 넘침이 없다. 책 지면의 하단 쪽 번호와 사진 크레디트를 원본대로 유지한다.
- 모바일에서 줄바꿈을 숨길 때 `까지.서로`, `필요한지.지금`이 붙던 소개문은 공백 보완 후 정상 표시된다. 최종 모바일 스크린샷에서 직접 확인했다.

## 확대 UI 회귀 검사

두 브라우저·두 화면 크기에서 운영 대시보드 1장과 책 표지·내지 5장을 검사했다.

- 기본 모드는 화면의 사용 가능 영역 안에 들어오며 원비율을 유지한다.
- 원본 모드에서는 실제 이미지 픽셀 크기로 표시한다.
- Escape로 닫으면 호출한 이미지 버튼에 초점이 돌아온다.
- 뷰어 버튼은 높이 48px, 대화상자는 모서리 16px다.
- 대시보드의 기관 로고 제외 마스크가 확대 화면에서도 유지된다.

최종 PC·모바일 뷰포트 캡처를 직접 열어 TEAM의 편집 지면, CONTACT의 폼·사례·FAQ, 책과 대시보드의 전체 형태를 확인했다. 검수 범위에서 미해결 시각 결함은 없다.

## 검사 이력과 증거

- `initial/`: 행간·모바일 문장 간격 보완 전 빌드. Chromium 진행 기록 98개와 스크린샷을 보존했다.
- `final/results-before-lazy-visibility.json`: 최종 빌드 첫 실행의 원본 결과. 197/199 통과, WebKit PC의 화면 밖 lazy 이미지 2건을 노출 전에 측정해 `naturalWidth=0`으로 판정한 기록이다.
- `final/image-visible-recheck.json`: 해당 2건에 대해 이미지를 화면 안으로 스크롤한 후 로드 완료와 원비율을 다시 확인한 결과. 2/2 통과했으며 앱 소스는 바꾸지 않았다.
- `final/results.json`: 고유 검사명으로 위 2건의 재확인 결과를 반영한 최종 199개 기록이다. 반복 실행 횟수를 새 통과 건수로 더하지 않았다.
- `check.cjs`: 후속 재사용 시에도 lazy 이미지를 먼저 화면 안에 들인 뒤 측정하도록 순서를 보완했다. 이미지 decode 대기는 유한하며 실제 로드 상태와 비율을 별도로 판정한다.
- `final/*.png`: 최종 통합 빌드의 실제 뷰포트 이미지. `*-visible-image-recheck.png`는 WebKit 이미지 재확인 장면이다.

검수는 로컬 통합 화면을 대상으로 한다. 실제 문의 전달, 외부 운영 사이트 배포, 주문·계약·성과를 검증한 결과가 아니다.
