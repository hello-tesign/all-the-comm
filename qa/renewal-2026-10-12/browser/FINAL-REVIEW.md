# 브라우저 QA 및 독립 디자인 검수

검수일: 2026-10-12. 대상: 격리 QA 서버 `http://127.0.0.1:4183`. 사용자 미리보기 4173에는 테스트 데이터를 보내지 않았다. 이번 검수에서는 사이트 파일과 한국어·영어 콘텐츠를 수정하지 않았다.

## 기능 검증 결과

- 전체 실행: **388개 중 387개 통과**, 모션 초기 준비 시간을 넘긴 1개 실패. 원본 `results.json`과 `summary.md`를 그대로 보존했다.
- 실패 항목 표적 재검증: **2개 중 2개 통과**. `results-motion.json`과 `summary-motion.md` 참조. 원래 실패했던 동일한 모션 정지·재생 검증과 모션 감소 설정 검증을 실행했다.
- 준비 전 버튼이 의도대로 disabled인 동안 헤드리스 소프트웨어 GPU가 초기화되는 시간을 고려하여, renderer 준비 완료를 최대 15초 기다리도록 테스트만 보정했다.
- 중간 표적 검증에서 캔버스 스크린샷에 겹쳐 있는 버튼의 hover 테두리가 픽셀 차이를 만들었다. 첫 캡처 전에 포인터를 버튼 밖으로 옮겨 hover 조건을 맞췄으며, 이후 다른 위치로 포인터를 이동해도 정지 캔버스 PNG의 SHA-256이 완전히 동일했다. 중간 결과는 `results-motion-hover-round.json`에 보존했다. 화면 일부를 숨기거나 실제 조형을 마스킹하지 않았다.
- 위 재검증을 반영한 **현재 미해결 UI 기능 실패는 0개**다. 388개 전부를 한 번에 통과했다고 표현하지 않는다.

Chromium은 390/768/1440px, Firefox와 WebKit은 390/1440px에서 검증했다. 한국어·영어 16개 경로의 응답, 제목·메인·내비게이션, 언어 전환, 가로 넘침, 이미지, 콘솔 오류를 확인했다. 모바일 메뉴 열기·Tab 순환·Escape·초점 복원, WORKS 10개 서비스와 TEAM 9개 역할의 클릭·키보드 전환, 프로젝트 필터, 문의 유효성 검사와 전송 실패 시 입력 보존도 통과했다.

모든 변경 요청은 브라우저에서 차단하거나 합성 503으로 응답했다. 실제 문의 접수·메일 수신·배포·실서비스 성능의 증거는 이 UI 검증 범위에 포함하지 않는다. 서버/API 검증은 담당 에이전트의 별도 결과를 참조해야 한다.

최근 한국어 Home/WORKS/TEAM/CONTACT의 데스크톱·모바일 캡처와 실제 히어로 모션을 검수했다. 아래 수치는 내부 평가이며 수상 가능성이나 외부 인증을 뜻하지 않는다.

## 한국어 후속 정교화 우선순위

1. 공개 허가를 받은 실제 프로젝트에 문제·판단·실행·결과를 연결한 짧은 사례를 추가한다. 병원 경험은 강점으로 보여주되 종합 대행의 다른 분야를 밀어내지 않는다. 허위 고객·성과·포트폴리오는 추가하지 않는다.
2. 현재의 서비스·역할 공통 표현 중 중요한 몇 개는 실제 산출물과 작업 과정 중심으로 차이를 만든다. 단순히 카드 수나 장식 개체 수를 늘리는 방식은 피한다.
3. 보조 카피의 구체성, 문의 파일 선택의 한글 안내, 작은 레이블의 대비·크기를 실제 한국어 검토에 맞춰 다듬는다.

사용자의 최신 지시에 따라 세부 개선은 한국어에서 먼저 검토하고, 영어는 한국어 승인 후 한 번에 동기화한다. 이번 QA에서는 영어를 현재 상태 그대로 검증했으며 문안이나 레이아웃을 변경하지 않았다.
