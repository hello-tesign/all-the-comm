## 현재 기준

**국문 PC → 국문 모바일 → 영문 PC → 영문 모바일 순서로 진행한다.** 현재 국문 PC의 사례·내용·시각 표현·전역 모션을 고도화한 상태다. 사용자 결정과 영문 동기화 목록은 `docs/LOCALIZATION_WORKFLOW.md`. 이후 세부 수정 때 영문 문구를 매번 작성하거나 영문 전용 검수를 반복하지 않는다.

**최신 상태는 문서 마지막 ‘편집 정리와 균등한 사례 프레임’ 절이다.** 사용자는 메뉴·상위 구조를 수용했지만 산만한 글과 사례 이미지 편집을 지적했고 FreeFrontend의 정갈함을 참고로 제시했다. 국문 전체를 같은 편집 기준으로 다듬었다. 아래 앞부분의 조형·소재 선정 및 점수는 변경 전 이력이다.

## 반영 내용

정식 자료에 맞춘 5개 상위 메뉴 + 상담 CTA, HOME 서비스8·WORKS 서비스10·TEAM 역할9, 회사소개·업무과정·사례·실제 문의접수·개인정보 페이지. 종합광고대행사 포지션이며 병원은 서비스 중 하나다.

공식 AI 로고의 벡터를 추출해 사용했다. 민트·네이비의 디자인시스템, 맞춤 3D 심볼, 글라스 서비스와 역할 탐색, 자사 작업의 브랜드 응용 장면, 채널별 타이포그래피 구성을 적용했다. 이전의 선 목록과 9개 반복 역할 상자를 교체했다. Three.js는 홈에서만 동적 로드하며 GSAP·CSS/WAAPI·View Transitions와 직접 구성한 HyperFrames 영상을 사용한다.

문의는 실제 비공개 관리자 접수함에 저장한다. 첨부 다운로드·동의·검증·중복 확인·입력 보존과 사례 등록/수정/삭제/공개/정렬/대표 노출 기능을 구현했다. 공개 여부를 직접 주소와 미디어에도 적용한다. 관리자 영문 입력 기능은 준비돼 있으나 이후 국문과의 문구 동기화는 국문 확정 뒤에 한다.

## 데이터와 운영

`.private/server`에는 사용자 문의·첨부·사례와 로컬 관리자 비밀번호가 있다. Git이나 공개 ZIP에 넣지 않는다. 기존 데이터가 있으면 빌드/재시작이 초기 사례로 덮어쓰지 않는다. 자료가 손상되면 실패로 종료한다. 상세 조건은 `docs/admin-server.md`.

운영 공개 전 남은 항목: 실제 Node 호스팅과 영속 데이터 볼륨, HTTPS 역방향 프록시와 실제 IP 정책, 관리자 비밀 설정, 백업·개인정보 보관/삭제 책임, 정식 도메인·공개 상태 확인. 자동 이메일은 연결하지 않았다. 접수 완료는 관리자 저장 완료이지 이메일 수신 증명이 아니다.

외부 고객 실적·인력 이력·성과 수치는 자료 없이 만들지 않았다. 최초 구현의 자사 리뉴얼 1건에, 10월 12일 후속 작업에서 사용자가 허용한 제작자 사이트·소프트웨어 5건을 국문 전용으로 추가했다. 현재 국문 6건, 영문은 기존 자사 1건이다. 신규 외부 고객 사례는 출처와 수행 관계를 확인한 뒤 관리자에서 추가한다.

## 후속 반영 — 전체 국문 PC 구성과 모션

이 절은 위 포트폴리오 작업 이후의 최신 상태다. 사용자 지시: ISOS는 최소 완성도 참고이며 기술은 자율적으로 선택한다. 참고 효과를 그대로 재현하는 대신 올더의 정체성·제작물·읽기·탐색을 기준으로 전체 화면을 다듬었다. 원본 HTML 및 별도 ISOS 프론트엔드 분석은 `docs/isos-reference-audit.md`에 있다.

### 반영

- 새 모듈: `src/isos-motion.js/css`, `src/scroll-story.js/css`. 국문 1060px 이상에서 적용. 제목 원문·br/em·동적 사례 제목을 보존하고 단어 마스크, 문장 강조, SVG 선 전개, 채널 레이어, 푸터 반응을 연결했다.
- 홈 대표 사례 3개에도 포트폴리오 전개를 적용했다. 전역 읽기 진행선은 하나만 노출한다. 기존 GSAP/WAAPI와 신규 모듈이 같은 대상을 중복 제어하지 않게 조정했다.
