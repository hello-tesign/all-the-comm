# 한국어 PC 포트폴리오 독립 시각 검수

2026-10-12. 대상: `http://127.0.0.1:4173`, Chromium 1440×1000, deviceScaleFactor 1, reduced motion. 한국어 WORKS 목록과 소적두·Review Atelier 상세만 검수했다. 영어·모바일·사이트 소스는 수정하지 않았다. 모든 변경 요청은 브라우저에서 차단하도록 구성했으며 실제 시도된 변경 요청은 0건이다.

**최신 상태: 아래 상세 본문 배치와 썸네일 하단 잘림 지적은 수정 후 재검수에서 모두 해결 확인했다.** 최초 관찰 기록은 보존하며, 마지막 ‘수정 후 재검수’가 현재 판정이다.

## 확인 결과

- 세 경로 모두 HTTP 200. 화면 가로 넘침 0. 사용된 포트폴리오 이미지가 모두 로드됐다.
- WORKS에 소적두, SoulReset, Review Atelier, TESIGN Radar, Tesign OS와 자사 리뉴얼 6개 항목이 표시된다. 브랜드·커머스·서비스 웹·편집 도구를 화면으로 비교할 수 있어 기존 단일 자사 사례보다 제작 범위가 분명하다.
- 목록과 상세에 제작자 콘셉트, 제작자 프로젝트, 제작자 프로토타입, 내부 도구 표기가 있다. 올더커뮤니케이션이 수행한 유료 고객 수주로 단정하는 문구는 검토 영역에서 발견되지 않았다.
- 소적두 화면의 신제품 개발 프리뷰 고지가 유지됐고 상세 본문에 생성형 제품·패키지, 개발 가정, 미출시·미결제·미판매 구분이 명시됐다.
- Review Atelier는 이미지 안의 ‘시연용 가상 제품’과 상세의 합성 자료·고정 응답 설명이 일치한다. 실제 앱 인터페이스를 보여 주되 실제 AI 원고 생성 품질이나 유료 운영 실적으로 주장하지 않는다.
- 소적두 상세 이미지 두 장은 1440×900을 1310×819로, Review Atelier는 1600×1050을 1310×860으로 표시해 원본 종횡비가 유지된다. 상세에서 읽을 수 있는 크기이며 전체 화면 링크도 제공된다.

## 필수 수정 전달

**상세 본문의 제목과 설명을 같은 읽기 흐름으로 연결해야 한다.**

`.case-story`는 현재 2열(약 473px / 728px)인데 3개 자식인 영문 레이블, 제목, 본문을 자동 배치한다. 제목은 오른쪽 첫 행, 본문은 왼쪽 다음 행에 놓여 연결이 끊긴다. 소적두와 Review Atelier 상세 공통이다. 본문을 오른쪽 제목 아래 열에 명시적으로 배치하거나 제목과 본문을 한 콘텐츠 묶음으로 구성하는 것을 권한다.

근거: `sojukdoo-story-viewport.png`. 원본 사이트는 검수자가 수정하지 않았다. 이 지적은 루트 담당자에게 전달했다.

## 비차단 관찰

- 목록의 보조 카드들은 약 636×398 박스로 높이를 맞춘다. SoulReset은 원본 비율과 일치하지만 Review Atelier(표시 이미지 높이 418px), TESIGN(442px), Tesign OS(688px)는 부모 overflow에 의해 하단이 잘린다. 가로·세로 비율 왜곡은 없고 제목·타입·설명이 별도로 보이므로 썸네일 미리보기로는 이해 가능하다. Tesign OS 상세와 원본 열기에서는 전체 작업 흐름을 확인할 수 있어야 한다.
- 실제 UI 화면의 작은 텍스트를 썸네일에서 모두 읽기는 어렵다. 이것은 스크린샷의 한계이며, 카드의 한 줄 소개와 상세의 큰 이미지가 설명을 보완한다.
- 이번 검수는 디자인·콘텐츠 표기 검수다. 클릭·필터·API·관리자 업로드 및 실제 운영 증거는 루트 담당자의 기능 검증 결과와 구분한다.

## 수정 후 재검수 — 두 항목 해결

루트 담당자의 빌드·4173 재시작 후, 동일 Chromium 1440×1000의 한국어 PC 화면에서 지적한 두 항목만 재검수했다.

1. **상세 본문 연결: 해결.** 소적두와 Review Atelier의 과제·방향·실행, 총 6개 블록 모두 제목과 본문의 왼쪽 좌표가 647.67px로 같고 본문이 제목 바로 아래에 배치된다. 본문 `grid-column: 2`, 제목 하단과 본문 상단 간격 25px. 실제 캡처에서도 제목·설명이 한 묶음으로 읽힌다.
2. **목록 캡처 하단 잘림: 해결.** 포트폴리오 이미지 5개 모두 표시 박스 안에 들어간다. 기존에 넘치던 Review Atelier·TESIGN Radar·Tesign OS도 이미지 요소 크기가 부모 636×398px를 초과하지 않으며 `object-fit: contain`, `min-width/min-height: 0`이 적용됐다. 실제 화면에서 Tesign OS의 세로 캡처 하단까지 확인했다. 화면 양옆 여백은 원본 비율을 유지한 결과다.

추가 변경 요청·폼 전송은 없었으며, 사이트 소스와 영어·모바일을 수정하지 않았다. 이번 두 지적에 대한 미해결 항목은 없다.
