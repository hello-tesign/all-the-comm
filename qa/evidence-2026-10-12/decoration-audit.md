# 국문 장식 영역 전수 점검과 교체 기준

2026-10-12, 변경 전 `http://127.0.0.1:4173`의 국문 8경로와 대응 영문 8경로 HTML을 읽었다. `before/baseline.json`과 원본 HTML에 이미지·제목·장식 선택자 수를 보존했다. 아래는 교체 전 상태이며 앱 소스를 수정하지 않았다.

## 서버·클라이언트 경로에서 빠지기 쉬운 부분

1. `scripts/server.mjs:491`에서 모든 공개 프로젝트 경로를 정적 파일보다 먼저 처리한다. `serveProject()`는 `dist/works/project/index.html` 또는 영문 공용 셸을 읽고 메타·본문 스칼라를 교체한다. 별도 하드코딩된 자사 HTML은 없다.
2. `scripts/server.mjs:318`의 `project.slug !== 'all-the-comm'` 분기 때문에 자사 사례의 cover/film은 API 값으로 바뀌지 않는다. **KO 공용 셸을 실제 이미지로 바꾸어야 자사 SSR이 바뀐다.** 비자사 SSR 교체 정규식이 `.case-cover`와 `.case-film`의 현재 외곽 구조를 기대하므로 외곽 클래스/순서를 유지하거나 서버와 동시 조정해야 한다.
3. `src/app.js:43`은 자사 목록 카드를 초기 DOM clone으로 만든다. `src/app.js:62` 역시 자사 사례 cover/film을 건너뛴다. API cover만 교체하는 작업은 불충분하다.
4. `scripts/build-renewal.mjs`의 `workArt()`는 목록 카드와 자사 상세에서 공동 사용된다. 국문만 새 표현을 제공하고 영문 분기는 원래 표현을 유지해야 한다.
5. `src/scroll-story.js:25,39,92`는 `.chapter-art`를 이동·복원한다. 실제 이미지 figure로 바꾸더라도 이 컨테이너를 유지하면 계약을 보존할 수 있다. path가 없어도 paths 배열이 비어 동작한다.
6. `src/isos-motion.js`는 기존 glass/lens/word/채널 종이를 선택한다. 장식 제거 후 없는 노드를 찾는 것은 방어돼 있지만 새 사진 모션을 그 선택자에 억지로 맞추지 않는다. 본문 opacity는 계속 1로 유지한다.
7. `src/app.js`의 커버 없는 프로젝트 fallback도 `.about-brand` 로고다. 국문 fallback은 제목/작업 정보 또는 정직한 이미지 준비 중 상태로 바꾸어 추상 로고가 재등장하지 않게 한다.
8. SSR `data-case-*` 본문은 저장된 프로젝트가 최종 권위다. 자사 설명이 여전히 '곡선/모션' 위주이면 빌드의 문장만 바꿔도 서버가 옛 내용으로 다시 덮는다. 공용 셸 이미지와 저장된 자사 설명의 일치를 실제 GET 응답에서 확인해야 한다.

## 후속 QA 범위

새 홈 3탭의 클릭·화살표·Home/End·포커스·예시 표시를 확인한다. 서비스 10개/홈 8개와 역할 9개의 패널 이미지·캡션·본문 의미 대응, PROCESS 4단계 실제 산출물을 확인한다. 3브라우저에서 이미지 로드, 가로 넘침, 런타임 오류, 실시간 감소 모션, 원문 선택 동작을 검사한다. 변경 전 영문 8페이지의 이미지·제목·장식 수를 기준으로 영문 유지 여부를 비교한다. 문의 제출과 서버 데이터 변경은 하지 않는다.
