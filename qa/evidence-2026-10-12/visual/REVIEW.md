# 국문 실제 제작물 중심 화면 검수

검수일: 2026-10-12. 검수 대상은 로컬 4173 국문 화면이며, 영어 변경·배포 검증·문의 제출은 포함하지 않았다. Chromium 1440×1000을 기준으로 56장 캡처를 확인했다. 보조 확인은 390×844의 홈·WORKS 병원·ABOUT·PROCESS·CONTACT와 1440×700 PROCESS이다. 캡처·관찰 기록은 이 폴더의 `capture.cjs`, `observations.json`에 있다. 모든 비조회 HTTP 요청을 차단했으며 실제 전송은 발생하지 않았다.

## 현재 관찰

- 홈 3개 선택 화면, 홈 서비스 8개, WORKS 서비스 10개, TEAM 역할 9개, 홈/전용 PROCESS 각 4단계, ABOUT, 자사 상세, CONTACT를 실제 화면에서 확인했다.
- 이 범위에서 이전의 장식용 3D·글라스 패널·추상 역할 아이콘은 보이지 않는다. 기능을 전달하는 화살표와 공식 헤더 로고는 남아 있다. 기존 장식 선택자를 통한 별도 DOM 확인도 노출 0건이다.
- 기존 상품 사진, 제작자 프로젝트 캡처, 개발 콘셉트와 자체 예시가 각각 표기되어 있다. 예시를 실제 유상 수주·보도·광고 집행 실적으로 주장하는 화면은 확인되지 않았다.
- 소적두 제조 현장 사진에는 ‘올더 구성원 사진이 아닙니다’가 붙어 있다. 사진 속 작업과 고객 사업을 이해한다는 옆 문장이 대응한다. 직원/대행사 촬영 현장 사진으로 표기하지 않는다.
- 홈 PROCESS에도 ‘분석 대상 예시 / 개발 콘셉트 / 구매 UI 시안 / 별도 내부 도구·검수용 데이터’ 구분이 보인다. 상품 사진 자체를 분석 산출물이라고 표현하지 않는다.
- 병원 예시는 예약·방문 준비·위치라는 실제 이용자의 질문을 중심으로 읽힌다. PR·영상·광고·인플루언서 예시는 자체 기획 예시임이 보인다. 광고의 제품 사진과 ‘단팥 한 입’ 카피는 맞는다.
- 전체 56장 기록에서 가로 넘침, 보이는 이미지의 로딩 실패, 페이지 오류는 0건이다. PROCESS 700px 높이에서 4단계 내비게이션과 캡션이 화면 안에 들어온다. 모바일 표적 화면에서는 순서대로 세로 스크롤 가능하며 가로 넘침은 없다. 이 확인은 모바일 전체 완성도 평가가 아니다.

## 읽기와 표현에 대한 판단

서비스 영역은 여러 작은 보고서 카드를 늘어놓는 구성에서 하나의 선택형 제작물 화면과 설명을 보여주는 구성으로 바뀌었다. 설명을 뒷받침하는 자료가 생겨 이전 추상 조형보다 역할을 이해하기 쉽다. 다만 PR의 구성 설명과 영상의 반복 사진은 아직 결과물의 구체성이 부족했으며 위 표로 구분해 전달했다.

화면 자료가 소적두에 집중되어 제품·콘텐츠·광고·과정 사이에서 같은 소재가 반복되는 한계는 남아 있다. 제작자 UI 캡처는 이를 일부 보완하지만, 지금 자료만으로 다양한 실제 고객 성과를 입증한다고 말할 수 없다. 특히 작은 UI 캡처는 화면 구조를 보여주는 데에는 유효하지만 세부 문구·운영 수치를 읽는 증거로 사용하면 안 된다. 이 검수에서는 점수를 임의로 부여하거나 목표 점수 달성을 선언하지 않는다.

## 최종 표적 확인

자사 상세 첫 표지의 회귀만 다시 열어 확인했다. 표지 경계는 y110.08–760.08이며, 이미지 경계는 y155.08–715.08(높이560px), ‘화면 크게 보기’ 안내는 y646.08–691.08이다. 둘 다 표지 안에 완전히 들어온다. 이미지의 object-fit은 contain, 안내의 visibility는 visible/opacity 1이다. 실화면에서도 문의 폼 하단과 확대 안내가 함께 보이며 잘림이 없다.

이번 검수에서 발견한 필수 수정·예시 구체성 지적은 모두 반영되어 재확인했다. 검수 범위 내 남아 있는 필수 시각 수정은 없다. 이는 국문 표적 화면의 표시·의미 대응 확인이며, 실제 고객 성과나 운영·배포 검증, 공모전 수준 달성 또는 임의의 90점 인증으로 해석하지 않는다.
