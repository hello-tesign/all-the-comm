**통합 601개 검사 통과, 기능 검사 실패 0, JavaScript 오류 0, 문의·쓰기 요청 시도 0.** 이는 실제 검사 항목 수이며 디자인 수준의 점수가 아니다.

## 검사한 내용

- 국문 9경로 × 3브라우저 = 27개 페이지 기록: 홈, ABOUT, PROCESS, TEAM, WORKS, CONTACT, PRIVACY, 자사 CASE, 소적두 CASE.
- 기존 3D 심볼·유리판·장식 SVG·렌즈·궤도·가상 목업 선택자 0개. 공식 회사 로고와 기능상 필요한 조작 표시는 보존했다.
- 홈 3장면의 실제 이미지, 제작자·콘셉트·검수용 자료 표기, 개별 사례 링크, 클릭·방향키·Home/End·순환 선택 및 단일 패널을 확인했다. 최종 3장면은 모두 640px 높이 안에 캡션이 포함됐다.
- 홈 8개·WORKS 10개 서비스와 TEAM 9개 역할의 업무 연결, 구체적인 제작 화면 또는 자체 구성 예시, 이미지 로드, 본문 가시성, 탭 선택과 키보드 동작을 확인했다.
- PROCESS 4단계의 사진·제안·제작 화면·검수용 도구와 단계 활성화, 홈의 4개 과정 패널 및 각각의 예시 성격 표기를 확인했다. 1단계는 기존 상품 사진을 분석 대상으로 보여주는 장면이며 실제 분석 보고서라고 주장하지 않는다.
- 실행 중 감소 모션을 켜면 이미지 마스크와 추가 모션이 해제되고 PROCESS의 원래 4개 이미지가 각 article로 복원된다. 다시 켜면 장면·읽기 선이 중복 없이 복구됐다.
- 표시된 콘텐츠 이미지와 선택한 모든 서비스/역할/과정 이미지의 실제 로드·대체 텍스트, 페이지 가로 넘침을 검사했다.
- 자사 CASE의 실제 문의 화면, 정확한 원본 비율, 두 캡처의 확대와 Escape 종료·원래 버튼으로 포커스 복귀를 확인했다. 마지막 수정 후 세 브라우저 모두 커버 높이 650px 안에 이미지 높이 560px가 들어갔다.
- 영문 8경로 SSR의 제목·이미지 목록·기존 그래픽 수가 변경 전과 같았다. 각 브라우저의 영문 홈·PROCESS에서 기존 그래픽을 유지하고 새 국문 모션이 활성화되지 않는 것도 확인했다. 자사 사례 공통 OG 커버 메타 변경은 별도이며, 영문 전체가 바이트 단위로 불변이라는 의미는 아니다.

PR의 가상 소포장 간식 보도자료와 영상 콘티의 단면→제품 전체→엔드 카피 3장면은 저장한 화면을 직접 확인했다. 실제 기사·촬영·집행 실적으로 표기하지 않는다. 로컬 UI 검증이며 배포, 외부 이메일, 신규 문의 저장 API 검증은 이번에 실행하지 않았다.

## 실행 기록과 집계 방식

1. `initial-lazy-image-result.json`: 최초 전체 27페이지. 570개 통과, Firefox 자사 하단 lazy 이미지 1개 시점 검사 실패.
2. `firefox-self-diagnostic.json` 및 PNG: 해당 이미지 HTTP 200, 뷰포트 진입 직후 naturalWidth 0에서 100ms 뒤 774로 정상 로드됨을 확인했다. 초기 테스트가 decode의 초기 reject를 대기 종료로 처리한 오류였다. load/error 이벤트를 기다린 뒤 decode하도록 테스트를 수정했다.
3. `final-targeted-results.json`: 홈·WORKS·자사 CASE의 최종 변경분만 3브라우저 재검증, 361개 모두 통과. 예시 원고, 3장면 고정 높이, 고해상도 문의 캡처와 확대 버튼 등을 확인했다.
4. `self-cover-results.json`: 마지막 자사 커버 CSS 변경에 대해 해당 한 경로만 3브라우저 확인, 44개 모두 통과.
5. `results.json`: 동일 이름의 검사는 최신 증거로 대체하고 변경되지 않은 경로의 기존 증거를 유지했다. 중복을 합산하지 않은 고유 검사 601개다. 각 검사에는 원본 실행 파일을 가리키는 `evidence`가 있다.

`ui-test.cjs`가 검사 스크립트이며 `merge-results.cjs`가 집계 스크립트다. 처음 테스트 파일의 함수명이 Node의 process 전역과 충돌했던 시작 오류도 실행 전에 바로 수정했으며 사이트 오류로 집계하지 않았다. 기존 ISOS 413개·마무리 179개 결과는 별도 폴더에 그대로 보존했다.

최종 폴더의 PNG는 33장이다. 페이지 상단 27장, 마지막 장면·PR/영상·확대 화면 5장, Firefox 지연 로딩 진단 1장이다. 모든 접속은 GET/HEAD/OPTIONS만 허용했고 상담 제출은 하지 않았다.
