# 구조 설계 기획서 검수 기록

2026-10-12. 최종 산출물은 deliverables/planning-2026-10-12의 DOCX, 동일 내용 Markdown, 사이트 트리 Markdown이다. 원본 수신 자료와 홈페이지 소스는 수정하지 않았다.

## 내용 검수

- S01~S04 순차 텍스트 추출 및 버전 비교. S03의 8/10/9를 기준으로 S04 상세 기능 보완.
- 원문 메뉴 5개와 별도 상담 CTA 유지. 서비스10과 사례분류9를 구분.
- 사례 관리 필수, 문의 이메일 또는 관리자 전달 필수, 병행 운영은 제안으로 구분.
- 로고 한글형/영문형 확인과 완전한 영문 사이트 범위 미정을 구분.
- 독립 감사 후 개인정보 동의 미리 선택 금지·내용 열람, 사이트맵, 콘텐츠/영상 두 업무 연결을 보완.

## 참고 HTML 검수

- 정적 코드 먼저 분석하고 Chromium 로컬 렌더링 수행. HTTP(S) 요청 차단. 실제 문의 전송 없음.
- 1440×1000, 390×844, 1440×1000 reduced motion. 실행 오류는 각 조건 0건.
- 가로 넘침: 1440 조건 두 가지에서 확인. 390 조건에서는 없음.
- 상대 이미지 3개 미수신·로드 실패. 국문 단일 페이지, 언어 전환 없음.
- 캡처와 기계 판독 결과: reference-qa/. 정적 분석: reference-review.md.
- 이것은 참고 파일의 제한적 감사이며 새 사이트 전체 QA 통과 기록이 아니다.

## DOCX 검수

- python-docx로 생성, Word COM으로 PDF 15페이지 렌더, Poppler PNG 변환.
- 시각 검수: 1~7페이지 자산 검토 담당, 8~15페이지 주 담당. 마지막 수정 4·6·13페이지 재렌더 후 주 담당 재검수.
- 트리 연결선·들여쓰기, 표 행 분할, 텍스트 잘림·겹침, 페이지 번호, 본문·주석 가독성 확인. 필수 레이아웃 결함 없음.
- DOCX ZIP 무결성, 제목 15개, 요구 키워드, PDF 15페이지와 각 페이지 텍스트 존재 확인.
- 기술 출처 6개는 DOCX 내 외부 하이퍼링크. 웹 기획 구현·도구 설치 성공을 주장하지 않음.
- 렌더와 중간 초안은 내부 QA 파일로만 보관. 납품 파일 SHA-256은 deliverables 폴더 manifest.json에 기록.
