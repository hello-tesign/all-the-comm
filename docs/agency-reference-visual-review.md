## 올더커뮤니케이션에 바로 적용할 기준

1. 홈의 3개 장면은 제품·브랜드 웹·업무 도구처럼 결과가 서로 다른 사례로 구성한다. 실제 제품 사진이나 UI가 화면에서 가장 큰 요소가 되게 한다. 각 장면에는 사례 이름, 제작자/콘셉트/자사 작업 구분, 구체적 작업 범위를 붙인다.
2. 서비스 10개와 TEAM 9개는 사진을 바꾸는 것만으로 끝내지 않는다. 콘텐츠는 원고나 편집 결과, 디자인은 완성 레이아웃, IT는 실제 관리 UI처럼 본문이 말하는 작업을 이미지에서도 확인할 수 있어야 한다.
3. PROCESS의 분석·전략·실행·보고 단계는 실제 문서 일부, 구성안, 제작 화면, 검수·인계 결과로 연결한다. 복잡한 표나 숫자를 장식으로 만들어 성과처럼 보이게 하지 않는다.
4. 이미지를 매번 유리판·렌즈·동일한 작은 카드 안에 넣지 않는다. 제품은 질감이 보이는 크롭, 웹은 화면이 읽히는 비율, 문서는 핵심 부분 확대처럼 각 소재의 정보를 우선한다.
5. 모션은 선택한 사례 교체, 결과물의 확대, 단계별 산출물 연결에 쓰고 본문을 가리지 않는다. 첫 장면의 정지 이미지와 텍스트는 모션 준비와 무관하게 읽혀야 한다.
