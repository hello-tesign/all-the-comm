# 국문 PC 글자 크기 조정

사용자 요청: PC의 모든 글자를 위계에 따라 한 단계 키우고 메인 타이틀은 유지한다.

## 적용 범위

- 국문 1060px 이상: 상단 메뉴, 소개 문구, 본문, 제목, 서비스 탭, 사례 캡션, 입력 양식, 푸터, 상세 페이지 및 확대 뷰어.
- 홈의 회사 슬로건 H1은 기존 `clamp(72px,5.6vw,96px)` 그대로 유지한다.
- 모바일·태블릿(1059px 이하)과 영문은 기존 값을 유지한다.
- 캡처 이미지와 HTML로 구성한 포트폴리오 작품/의료진 인터뷰 예시 안의 글자는 원본 비례를 유지한다. 작품 바깥의 제목·설명·캡션은 확대한다.

## 크기 체계

기존 값에서 `12 / 14 / 16 / 18 / 20 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 56 / 64 / 72…`의 다음 단계로 이동한다. 9–11px로 작았던 안내 문구는 최소 12px로 통일한다. 가변 크기 제목은 최소·최대와 중간 viewport 비율을 함께 조정한다.

| 용도 | 기존 | 적용 |
|---|---:|---:|
| 일반 본문 | 16px | 18px |
| 캡션 | 12px | 14px |
| 버튼·텍스트 링크 | 14px | 16px |
| 사례 제목 | 24px | 28px |
| 서비스 제목 | 32px | 36px |
| 일반 섹션 제목 최대값 | 44px | 48px |
| 서브페이지 제목 최대값 | 64px | 72px |
| 메인 히어로 H1 | 72–96px | 동일 |

`src/desktop-typography.css`에서 한 번에 관리한다. 기존 선언의 크기는 CSS 변수의 fallback으로 보존해, 데스크톱 규칙이 비활성인 모바일과 영문에서는 이전과 같은 값이 계산된다. 본문 행간 1.6, 콘텐츠 폭 1280px, 기존 8px 간격 체계와 48px 주요 컨트롤 높이는 유지한다. 확대를 위해 페이지 zoom이나 transform을 사용하지 않는다.

## 확인 방법

`qa/type-scale-2026-10-13`에 변경 전후의 실제 브라우저 계산값과 화면을 보관한다. 국문 PC 1440px/1060px에서 9개 경로, 모바일/영문 대조군에서 폰트 크기와 행간을 비교한다. 별도로 서비스·TEAM 탭과 CONTACT 입력창을 확인한다. 카피·이미지 변경이나 문의 전송, 외부 배포는 포함하지 않는다.
