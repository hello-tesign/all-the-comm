# 메인 브랜드 히어로 — 2026-10-13

## 사용자 결정
메인 히어로는 회사의 얼굴이다. 개별 사례·제품·포트폴리오 캐러셀을 사용하지 않는다. 회사의 슬로건, 적절한 이미지, 이를 뒷받침하는 기술을 함께 설계한다. FreeFrontend에서 참고한 본문의 정갈함과 히어로의 강한 인상을 구분한다.

## 최종 구성
- 슬로건: 전략은 명확하게. 표현은 강렬하게.
- 설명: 브랜드 전략부터 콘텐츠·광고·PR·웹까지. 기업에 필요한 마케팅을 기획하고 실행합니다.
- 이미지: 도시 보행자의 흑백 실사. 고객을 이해하고 소통하는 마케팅의 대상을 표현한다. 회사의 직원·사무실·수주 사례나 직접 촬영 결과라고 표시하지 않는다.
- CTA: 마케팅 상담, 제공 업무 보기. 사례는 아래 대표 프로젝트 영역에서 소개한다.
- 근거: 정식 지시의 통합 수행 범위, 의학 취재·병원 홍보의 전문 배경, 진행·예산·결과 공유 기준. 연혁·고객수·성과 수치는 만들지 않는다.
- 기술: 반응형 WebP 800/1280/2400, 우선 로딩, 실제 HTML 슬로건, 기존 단어 마스크 전개, 사진900ms 마스크와 스크롤48px 이내 이동. 반복 재생 없음. KO1060px 이상·동작 줄이기 해제에서만 사진 모션. 화면 밖/숨김 탭 중지, 종료·모션 감소시 원상복구.
