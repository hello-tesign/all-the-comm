# 국문 PC 전체 콘텐츠 구도 — 2026-10-13 후속

## 목표

종합광고대행사의 폭과 의료 커뮤니케이션의 깊이를 함께 보여준다. 단순히 페이지 길이를 늘리는 대신, 각 페이지에서 의뢰 기업이 판단할 질문을 해결한다. 모든 탑메뉴 페이지에 실제 제작 이미지와 사례를 넣는다. 앞선 ‘ABOUT·TEAM의 모든 사례 이미지 제거’ 방침은 폐기한다.

## 중복 제어

같은 대형 대표 화면을 여러 탑메뉴의 주인공으로 반복하지 않는다. 홈의 탐색용 요약과 WORKS 목록→상세는 필요한 재사용이다. 페이지 본문은 서로 다른 결과물·다른 화면을 선택하고, 무엇을 보여주는 자료인지 설명한다. 병원 강점은 HOME의 짧은 연결과 ABOUT의 근거 설명, WORKS의 의뢰 범위로 역할을 나눈다.

## 시각 체계

- 기존 ink·green·warm-paper 색과 서체를 사용한다. 국문 shell 최대 폭은 1280px로 통일한다. 새 팔레트·새 로고·임의 3D를 추가하지 않는다.
- 큰 편집 지면처럼 이미지와 제목·본문을 구성한다. 둥근 카드 나열, 글라스 패널, 장식 아이콘, 의미 없는 숫자 배지는 사용하지 않는다.
- 간격은 8 / 16 / 24 / 32 / 48 / 64px 체계. 큰 섹션 여백은 PC 96px·태블릿 80px·모바일 64px, 열 간격 48/64px. 본문 16–18px·행간 1.6, 캡션 12–13px. 이미지와 글의 비율은 내용에 맞춰 정한다.
- 버튼과 입력 높이 48px, 텍스트 링크 최소 44px. 모서리는 컨트롤 8px·포트폴리오 프레임 12px·확대 뷰어 16px로 구분한다. 편집 지면까지 둥근 카드로 감싸지 않는다.
- 웹 캡처는 원래 비율을 유지한다. 책 지면은 화면 높이 안에서 전체가 보이게 하고 상세 확대를 연결한다.
- 모션은 기존 선택/스크롤 프레임 전개를 활용한다. 내용은 즉시 읽히고 reduced-motion에서도 동일한 정보가 남는다.
- 설명에는 고객의 과제, 실제 산출물, 확인할 포인트가 있어야 한다. 인원·매출·수주·치료 성과를 임의로 만들지 않는다.

## 구현과 검수 단위

공통 구도에 맞춘 페이지별 모듈을 병행 제작하고, 빌더에서 한 번에 연결한다. 모듈이 완성될 때마다 공개 화면을 개별적으로 덧붙이지 않는다. 통합 빌드 후 탑메뉴 전체를 같은 기준으로 시각·기능 검수한다. 영문은 최종 국문 확정 후 반영한다.
