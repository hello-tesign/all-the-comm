# 국문 하위 페이지 재구성 (2026-10-14)

ABOUT · PROCESS · TEAM · WORKS · CONTACT를 홈 스토리와 같은 디자인 언어로 다시 짰습니다. 영문 페이지와 프로젝트 상세는 이번에 손대지 않았습니다.

- 소스: `src/story/pages.mjs`(마크업), `src/story/sub.css`(스타일), `src/story/sub.js`(상호작용)
- 공통 토큰과 모티프는 `story.css`에서 가져옵니다.
- 빌드: `scripts/build-renewal.mjs`가 국문일 때만 새 본문을 넣습니다. 이때 body 클래스에 `sub-page`가 붙습니다.

## 공통 구성

- **히어로**는 페이지 번호, 큰 제목, 로고 실루엣 창, 페이지 목차로 이뤄집니다. 로고 창 안의 장면은 페이지마다 다릅니다.
  - ABOUT·WORKS: 실제 작업 화면이 흐릅니다(릴).
  - PROCESS: 4단계 다이얼입니다.
  - TEAM: 9개 역할이 순서대로 켜지는 원형입니다.
  - CONTACT: 대화 예시입니다.
- **제목 등장**은 CSS로 한 번만 재생합니다. 기존 GSAP 제목 마스크(isos-motion)는 하위 페이지에서 쓰지 않습니다.
- **작업 화면**은 색 보드 위에 둡니다. 화면 캡처는 브라우저 프레임에, 포스터·책은 실물처럼 배치합니다.
- **카드 나열을 줄였습니다.** 대신 번호 행 목록, 표, 고정 레일, 열고 닫는 행으로 정보를 나눴습니다.

## 페이지별 구성

| 페이지 | 섹션 |
|---|---|
| ABOUT | 하는 일(기획 + 제작 + 운영 = 한 팀) · 의료 분야 배경(3열 + 파트너) · 제작 사례 2건 · 일하는 기준 5 · 회사 정보 · 상담 띠 |
| PROCESS | 4단계(왼쪽 고정 레일이 현재 단계를 표시. 단계마다 확인할 내용 / 함께 하는 일 / 전달하는 결과) · 진행 중 공유하는 것 4 · 상담 띠 |
| TEAM | 9개 역할(열고 닫는 행, 주요 산출물) · 프로젝트별 구성 예시 표 · 제작물 2건 · 상담 띠 |
| WORKS | 서비스 10 색인(마우스를 올리거나 누르면 오른쪽 미리보기가 바뀜. `/works/#서비스` 깊은 링크 지원. 모바일은 해당 행 아래에 펼침) · 프로젝트 목록(기존 API·필터 유지) |
| CONTACT | 연락 채널·진행 흐름 · 문의서(기존 마크업·검증·전송 그대로) · 의뢰 준비 자료 · 자주 묻는 질문 |

## 자체 판단으로 더한 문구 (확인 후 수정)

| 위치 | 내용 |
|---|---|
| PROCESS 단계별 '확인할 내용'·'함께 하는 일' | `pages.mjs`의 `checks`입니다. '전달하는 결과'는 기존 `stages.outputs`를 그대로 씁니다. |
| PROCESS '진행하는 동안 공유하는 것' | 진행 상황·수정 요청·집행 내역·변경 사항(기존 업무 기준의 문장을 풀어 씀) |
| TEAM 디자인 역할 산출물 | 웹·배너·브랜드 그래픽 / 카탈로그·인쇄 홍보물 / 패키지·사인 디자인 |
| TEAM 프로젝트별 구성 표 | 브랜드 런칭·병원 개원 홍보·홈페이지 리뉴얼·시즌 캠페인 4가지 **예시**(●주도 ○참여) |
| WORKS 서비스별 관련 작업 | 각 프로젝트의 `services` 값에 맞춰 연결했습니다. 영상·인플루언서·언론홍보는 맞는 공개 사례가 없어 '관련 사례 준비 중'으로 표시합니다. |
| CONTACT 히어로 대화 | '대화 예시'로 표시한 가상의 대화입니다. |
| ABOUT 의료 분야 제목 | 기존 "의학전문기자와 병원 홍보팀장 출신의 경험"을 "의학 취재와 병원 홍보, 현장에서 쌓은 경험"으로 바꿨습니다. 대상자와 기간이 확인되지 않은 이력을 단정하지 않기 위해서입니다(기획서 2장). |
