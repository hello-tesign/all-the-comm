### EA / Review Atelier

**권장 공개 제목:** 자료에서 원고, 원고에서 채널까지

**표기:** EA / Review Atelier · 자체 제작 사례 · 구현 프로토타입 · 합성 데이터 시연

**짧은 설명:** 제품 자료를 읽고 원고를 편집한 뒤, 근거 검수와 채널별 출력으로 이어지는 콘텐츠 작업대. 작성과 검수의 상태를 함께 보여 주어 확인되지 않은 문장이 완료본으로 넘어가지 않도록 구성했다.

**상세 소개용 문구**

- 과제: 제품 정보, 집필, 수정 이력과 채널별 출력이 따로 움직이면 같은 내용을 반복 편집해야 하고, 무엇을 확인했는지 추적하기 어렵다.
- 구현: 제품·자료 입력, 한국어 원고 편집, 이전 원고 이력, 근거 검수, HTML 출력 화면을 한 흐름으로 연결했다. 미검수 원고에는 초안 상태를 표시한다.
- 이번 화면에서 확인한 범위: 실제 UI에 합성 제품명과 자료를 입력하고, 고정 응답을 사용하는 별도 생성 흐름으로 원고를 만든 뒤 편집·검수·출력 탭을 열었다. 제품명·저장 상태·본문·수정 후 검수 필요 상태가 실제 앱에 표시됐다. 브라우저 JavaScript 오류는 0건이었다.
- 프로젝트 성격: PC 우선으로 개발한 편집 앱의 구현 시연이다. 공개 웹 운영, 신규 유료 고객, 실제 모델의 이번 원고 품질이나 고객 성과를 입증하는 자료는 아니다.

**권장 업무 분류:** IT / 서비스 기획 / 콘텐츠 시스템. 홈페이지의 서비스 ID로는 `it`, `content`, `strategy`를 연결할 수 있다.

**권장 이미지 대체 텍스트:** 가상 광채 쿠션 원고를 편집하는 Review Atelier 실제 화면. 제품 자료·원고 편집·근거 검수·HTML 출력 탭과 초안 상태를 표시한다.

**직접 확인한 원본 및 구현 근거**

- 현재 정적 앱: `dist/index.html`, `dist/assets/` — 기존 빌드를 읽기만 했다.

### Tesign OS

**권장 공개 제목:** 만들고, 확인하고, 전달하는 작업의 순서

**표기:** Tesign OS · 자체 제작 사례 · 내부 콘텐츠 제작 도구 · 검수용 데이터 화면

**짧은 설명:** 브랜드와 제품 자료를 홍보 문구·상세페이지·SNS 콘텐츠 제작으로 연결하는 운영자 작업대. 요청, 재료, 생성, 검수, 납품의 상태를 한 작업 안에서 관리한다.

**상세 소개용 문구**

- 과제: 채널마다 제작이 나뉘어도 제품의 사실, 표현 기준, 최종 검수본은 이어져야 한다.
- 구현: 브랜드·제품 자료, 작업별 결과물, 검수, 납품 이력을 연결했다. 검수 후 본문이 달라지면 콘텐츠 지문을 비교해 납품·출력·발행 경계를 다시 확인한다.
- 화면의 범위: 별도 검수용 브랜드와 제품으로 채널별 홍보 문구를 생성하고 검수·납품 처리한 실제 작업 화면이다. 화면 속 `75점`은 내부 규칙의 테스트 결과이며 고객 성과나 외부 품질 인증 수치가 아니다. 필요하면 본문 소개에서 점수를 전혀 언급하지 않는다.
- 프로젝트 성격: 1인 운영자의 내부 제작·검수 도구다. 고객이 가입하는 상용 SaaS, 자동 광고 집행, 실제 매출 상승, 무인 법률 검수 서비스로 소개하지 않는다.

**권장 업무 분류:** IT / 운영 설계 / 콘텐츠 제작. 홈페이지의 서비스 ID로는 `it`, `content`, `consulting`을 연결할 수 있다.

**권장 이미지 대체 텍스트:** Tesign OS의 검수용 브랜드 작업 화면. 요청 접수부터 검수와 납품까지의 단계, 제품 자료와 채널별 홍보 문구 결과물을 보여 준다.
