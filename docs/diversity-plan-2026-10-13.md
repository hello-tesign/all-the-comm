# 국문 포트폴리오 편중 수정

2026-10-13 사용자 지적: 종합 마케팅회사 홈페이지가 소적두 홍보처럼 보인다. 이전 기능 검증과 별개로, 소재 선정과 반복 배치가 잘못됐다. 기술보다 업종·고객 과제·산출물의 다양성을 먼저 바로잡는다.

## 편집 기준

- 소적두는 WORKS의 개별 사례와 해당 상세에서만 소개한다. 홈 대표 장면, 전역 서비스 예시, ABOUT, TEAM, PROCESS의 공용 소재로 쓰지 않는다.
- 홈 첫 장면부터 여러 업종을 함께 보여준다. 특정 브랜드 하나를 회사의 대표 얼굴로 만들지 않는다.
- 서비스마다 고객 과제에 맞는 산출물을 보여준다. 리테일 커머스, 서비스 웹, 환자 안내, 문화행사 포스터, 제조업 PR, 뷰티 브리프, 여행 콘티, 업무 도구는 다른 내용을 가진다.
- 기존 제작자 프로젝트와 새 자체 콘셉트를 구분한다. 실제 수주·광고 집행·보도·전환 성과를 자료 없이 만들지 않는다.
- 자체 예시는 실제 쓰일 원고와 디자인으로 제작한다. 업종 이름만 바꾼 템플릿이나 같은 사진의 반복을 다양성으로 세지 않는다.
- 사진은 원래의 프로젝트/제품 맥락에 맞게 사용한다. 사진 속 기관·제품을 새로운 가상 고객이나 자체 촬영 실적으로 바꾸지 않는다.

## 수정 대상

|영역|기존 문제|수정 기준|
|---|---|---|
|홈 첫 화면|빵 단면이 회사 전체의 대표 비주얼|여러 업종의 작업물을 한 화면에서 확인|
|홈 대표 사례|소적두가 첫 번째 큰 사례|서로 다른 업종 세 건을 우선 편집|
|전략·콘텐츠|같은 소적두 웹·패키지 반복|리테일 브랜드 경험과 별도 콘텐츠 결과물|
|영상·광고·PR·인플루언서|빵 사진과 간식 원고의 변형|여행/문화/제조/뷰티로 업종·형식 구분|
|ABOUT|식품 제조 사진으로 회사 설명|다른 분야의 제작물과 문제 해결 범위|
|PROCESS|상품→패키지→커머스도 소적두|단계별 판단과 서로 다른 제작 근거|
|TEAM|서비스 이미지의 식품 편중 재노출|역할에 맞는 원고·편집·캠페인·도구|
|WORKS|기존 여섯 건 중 소프트웨어 비중 높음|비식품 제작자 프로젝트와 자체 캠페인 추가|

국문 PC를 우선한다. 영문 동기화와 모바일 전체 고도화는 기존 순서를 유지한다. 이번 결과를 기능 검사 수로 미적 목표 90점에 도달했다고 표현하지 않는다.
