# 국문 우선 제작 및 영문 일괄 반영

2026-10-12 사용자 결정.

## 확정 작업 순서

1. 국문 PC: 정식 지시의 트리·메뉴·필수 기능을 대조하고 골격을 확정한다. 이후 각 파트의 메시지·실제 사례·이미지와 영상·모션·문의 전환을 고도화한다.
2. 국문 모바일: 확정된 PC의 내용과 표현을 모바일의 읽기·탐색·성능에 맞춰 구성하고 검수한다.
3. 영문 PC: 완성된 국문을 기준으로 한 번에 번역·편집·레이아웃·기능을 반영한다.
4. 영문 모바일: 확정된 영문 PC를 기준으로 번역 길이·줄바꿈·반응형·탐색을 마무리한다.

현재 국문 PC의 각 파트를 고도화한다. 메뉴·트리와 상위 구조는 유지한다. 사용자는 제작자 자신의 사이트·SaaS 캡처 및 더미·콘셉트 사례의 사용을 허용했다. 이를 제작자 프로젝트·프로토타입·콘셉트로 구분하고 출처와 수행 범위를 함께 표시한다. 확인되지 않은 고객 수주·성과 수치로 소개하지 않는다. 모션은 각 파트의 메시지와 사례를 보여주는 목적에 맞춘다.


앞으로 세부 디자인·문구·기능 수정은 국문을 기준으로 진행한다. 매 수정마다 영문 번역·영문 문구 조정·영문 전용 화면 검수를 병행하지 않는다. 현재 영문은 참고 가능한 기존 상태로 유지한다.

국문이 완성되고 확정된 뒤, 그 최종본을 기준으로 번역·메뉴·줄바꿈·반응형·SEO·문의 안내·사례 본문을 한 번에 영문에 반영하고 전용 검수를 수행한다. 공통 코드와 보안·기능 결함 수정은 공통 코드에 적용한다. 이를 영문 콘텐츠 확정으로 취급하지 않는다.
