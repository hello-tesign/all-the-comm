## 채택한 원칙

1. **이미지가 회사에 무엇을 맡길 수 있는지 설명해야 한다.** 실제 상품, 제작 화면, 사용할 산출물의 예시를 큰 비중으로 보여준다. 자사 로고를 크게 회전시키는 장면은 제거했다.
2. **사례에 수행 관계를 표시한다.** 실제 상품 사진, 제작자 웹, 개발 콘셉트, 검수용 내부 도구, 자체 작성 예시를 분리한다. 참고 회사의 사진·캠페인·고객 로고는 복사하지 않았다.
3. **움직임은 관계와 선택을 드러내야 한다.** 사용자가 선택한 제품/서비스/운영 사례의 프레임이 열리고, 본문·탭은 같은 위치에서 바로 읽힌다. 자동 순환하지 않는다.
4. **근거 없는 영역은 결과물의 예시로 설명한다.** 병원 안내 콘텐츠, 보도자료 원고, 광고 소재, 영상 콘티, 크리에이터 브리프를 자체 예시로 작성했다. 실적·집행·성과 수치로 바꾸지 않는다.
5. **회사 내부의 시각 점수보다 사용자의 판단을 우선한다.** 앞선 90점 평가는 이미지의 사업적 의미에 대한 사용자의 지적을 충분히 반영하지 못했다. 이번 작업을 그 점수로 자동 승인하지 않는다.
