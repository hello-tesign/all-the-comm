# 편집 정리 — 2026-10-13

## 최신 피드백
구조는 유지한다. 긴 설명, 추상어와 반복, 잡다한 사례 화면을 줄여 완성된 프로젝트의 인상이 나도록 편집한다. FreeFrontend의 정갈한 정보 위계와 일정한 이미지 규격을 참고하되 템플릿이나 예제 효과를 복제하지 않는다.

## 공통 편집 규칙
- 한 섹션은 한 가지 역할만 한다. 제목은 내용을 바로 알 수 있는 말로 쓴다.
- 사례 제목은 프로젝트명과 작업 종류. 한두 문장으로 만든 것을 설명한다. 배경 설명은 상세에서 읽는다.
- 수사적 질문, ‘읽히는/연결/함께/다음 행동/어디까지’의 반복을 줄인다.
- 섹션마다 긴 슬로건·영문 eyebrow·캡션·본문·산출물·하단 링크를 모두 되풀이하지 않는다.
- 비교할 사례 이미지는 같은 크기의 깨끗한 프레임에 넣고, 원본 비율을 유지한다. 여러 페이지나 작은 UI를 겹쳐서 장식하지 않는다.
- 실제 제작물/개발 시제품/자체 기획의 구분은 간결하게 한 번 표시한다. 실적·성과나 수주 여부를 새로 만들지 않는다.
- 기존 메뉴·주요 섹션·접수 기능, 8px 간격·1280px 폭·48px 버튼·1.6 행간은 유지한다.
- 국문 PC 우선. 모바일은 기본 깨짐 확인, 영어는 기존 표시를 보존한다.
