## 바로 사용할 우선순위

국문 히어로의 `소적두 기존 상품 사진 × 별도의 커머스 개발 콘셉트`, `SoulReset 실제 웹 화면`, `Tesign 실제 운영 도구 화면` 구성에 맞는 후보가 있다. 이 세 장면을 자동 순환시키지 않고 방문자가 선택하게 하는 방향은 제품·서비스·업무 결과의 차이를 직접 보여준다.

1. **소적두 단팥빵 단면** — 기존 상품 카탈로그 사진. 900px 정사각형이라 반폭 히어로에 적합하다. 팥의 질감과 먹는 경험이 즉시 보인다.
2. **소적두 빙수팥 300g 실물 패키지** — 제품명·원료·용량이 사진 안에서 식별된다. 600px이므로 작은 보조 장면에 적합하다.
3. **소적두 제조 현장** — 실제 브랜드가 사용하던 기존 현장 사진 계열. ‘사업을 이해한다’는 맥락은 강하지만 올더커뮤니케이션의 직원이나 촬영 현장으로 보이게 쓰면 안 된다. 현장 사진을 읽는 이유를 설명할 때만 사용한다.

최신 ‘팥부터.’의 빵·패키지·점포는 아래와 같은 기존 상품 사진과 별도다. 생성형 개발 콘셉트가 기존 상품의 실제 패키지나 출시 결과인 것처럼 두 자료를 섞지 않는다.

## 선택 원칙

- 사진 하나가 무엇을 설명하는지 한 문장으로 말할 수 없으면 넣지 않는다.
- 기존 판매 제품, 개발 콘셉트, 실제 구현 화면, stock, 미확인 출처를 같은 ‘고객 성과’로 묶지 않는다.
- 사람·제품·본문은 의미를 가진 이미지로 보여주고, 검증된 이미지가 없는 업무에는 자체 산출물 예시나 정확한 설명을 사용한다.
- 이번 결과물은 읽기 전용 자산 조사다. 복사·웹 최적화·적용은 루트 담당자가 선택한 파일에 한해 진행한다.
